# Dark Mode

![DavPanel dashboard in dark mode](/img/davpanel-screenshots/dashboard/dark-mode-window.png#screenshot)

DavPanel theme offers a built-in Dark Mode, which can be activated with a single click using the options located at the bottom left of the sidebar:

![Dark mode switch](/img/panel/v2/darkmodes.gif)

When Dark Mode is activated, it will apply to all DavPanel pages, including the login page.

Your Dark Mode preference is saved in your browser.
