Released on January 29, 2025

### 💅 Polish
- The [davcli user-login](https://dev.davpanel.com/cli/users.html#Login-as-User) command no longer logs into a user container; it now generates an auto-login link for the DavPanel UI.
- [DavAdmin Keyboard Shortcuts #834](https://github.com/stefanpejcic/OpenPanel/issues/834)
- Option to view raw activity log and download it from *DavAdmin > Users > single user > Activity* page.
- Commands 'davcli user-redis', 'davcli user-memcached', 'firewall-reset', 'php-available_versions' 'php-installed_versions' and 'php-ini' are removed.
- 'davcli api-list' is renamed to 'davcli api' and [extended to support: on|off|status|list](https://dev.davpanel.com/cli/api.html).
- `--ssh` flag is removed from 'davcli user-password' command.
- [Added option to delete notifications on DavAdmin > Notifications](/img/docs-content/MWHJK2nv-2026-01-28-12-19.png).
- Improvements to the user deletion and suspend processes.
