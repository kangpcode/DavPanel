Released on October 17, 2025

### 💅 Polish
- Added [flock](https://linux.die.net/man/1/flock) to `davcli update` command.
- Improvements to `davcli plan-apply`: the system now checks whether the new plan’s RAM limit is lower than the combined RAM usage of all running services. If so, a warning will be logged.
- https://php.watch/api/v1/versions is replaced in *DavPanel > PHP* and *DavAdmin > Setitngs > PHP* with https://php-versions-api.davpanel.org/
- Documented [Setting default user locale](https://davpanel.com/docs/articles/accounts/default-user-locales/#4-default-locale) and [added option in *DavAdmin > Settings > Locales* to set a default locale](/img/docs-content/px5kmYYX-slika.png).
- [Added option in in *DavAdmin > Settings > Custom Code* to execute bash script before starting DavPanel UI](/img/docs-content/CwzSfxJM-slika.png) using [`/root/davpanel_run_on_startup`](https://dev.davpanel.com/customize.html#Before-startup) file.
- [Added option to view cronjob execution log on *DavPanel > Advanced > CronJobs*](/img/docs-content/zXx0LDMm-slika.png).
- Improvements to *DavPanel > AutoInstaller* backend logic.
- Improvements to 'Information' widget on *DavPanel > Dashboard*.
- [Added `--docroot` flag to davcli domains-whoowns command](https://github.com/stefanpejcic/opencli/commit/f9bc92781bc68a2046ede74ab712ecc1cbd4b3ae)
- [`davcli domains-edit` command](https://dev.davpanel.com/cli/domains.html#Edit-domains) to cd into domain's docroot, or edit it's VirtualHosts file from the terminal.
