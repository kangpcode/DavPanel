### 🐛 Bug Fixes
- `davcli locale` installs the catalogs included with the local DavPanel release; no missing fork commit is downloaded.
- `davcli update` reads DavPanel tags from GHCR and uses `/usr/local/davadmin` for the admin binary.
- `davcli version` finds locally built DavPanel images in the configured GHCR namespace.
- `davcli email-server install` uses the bundled DavMail source under `/usr/local/share/davpanel`.
- DavPanel source installation includes all 16 components, static binaries, source integrity checks, and locally built panel, Caddy and FTP images.
- `davcli server-logrotate` no longer makes the nightly logrotate run fail: the Caddy logs config dropped its `podman exec caddy` reload (not needed with `copytruncate`, and blocked inside logrotate.service), and `/etc/logrotate.d/lfd` is made not group-writable so logrotate stops skipping it.
- `davcli server-logrotate` adds `maxsize` to the distribution's `/etc/logrotate.d/rsyslog`, so syslog filled by container output is rotated once it passes `logrotate_size_limit` instead of growing for a whole week.
- `davcli docker-backup` no longer fails random accounts with "error running archive-pre commands" when the account still has a `backup` container running: the leftover container is removed before the backup, and `files-list.sh` gives each run its own temp files so two runs can't collide on the backup_meta volume.
- DavPanel > Node.js, Python, Ruby, Java and n8n applications on Nginx and OpenResty: a stopped application no longer keeps the web server from starting. Nginx now looks up the application's container on every request, so only that application's URLs return 502 while it is stopped and they work again as soon as it starts. Applications installed before this keep the old proxy until they are reinstalled. [#1267](https://github.com/stefanpejcic/OpenPanel/pull/1267)

### 💅 Polish
- `davcli sentinel` webhook notifications now include the server hostname and public IP in the title, so you can tell which server sent them.
