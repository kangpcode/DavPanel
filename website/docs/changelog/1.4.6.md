Released on July 01, 2025

### 💅 Polish

- removed minecraft and mssql volumes form backup source selection on user panel.
- new option `activity_lines_retention` is added, setting number of lines to keep in user activity log - default is 1500.
- file downloads from DavPanel > FileManager are now sreamed in 8KB chunks and Admin configures the limits.
- added user_allowed dictionary representing features that user can access in davpanel ui, to output of `/api/dashboard`
- [Option to trigger a backup manually #539](https://github.com/stefanpejcic/OpenPanel/issues/539)
- added `?output=json` option for `/settings/modules` on DavAdmin.
- *DavAdmin > Settings > Modules* now indicates for each module if its Enterprise-only, Free or in BETA.
- *DavAdmin > Feature Manager > Edit* now indicates for each feature if its Enterprise-only, Free or in BETA.
- improvements to singe users page in DavAdmin.
- [added indicator in top-right corner on DavAdmin when service restart is needed after configuration changes](/img/docs-content/ncsSLZw1-2025-06-27-21-01.png).
- [services on *DavAdmin > Services > Status* now display if service restart is needed](/img/docs-content/9Fv8RS6H-2025-06-27-21-01-1.png).
* **New Settings for Administrators in DavAdmin → DavPanel Settings:**
  Admins can now configure the following:

  * Maximum file size for **Edit**, **View**, **Upload**, and **Download** actions
  * Automatic Trash cleanup after a specified number of days
  * Maximum time limit for **compress** and **extract** operations
  * List of extensions to allow **Edit** and **View** options for
  * List of extensions to allow **Compress** and **Extract** options for
  * 
    [View screenshot →](/img/docs-content/51x3ykqB-2025-06-27-18-43.png)
