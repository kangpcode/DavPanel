Released on November 20, 2025

### 💅 Polish
- Changing a domain’s PHP version via *DavPanel > PHP > Settings* will now attempt to disable the previous version, provided it’s not used by any other domain and isn’t set as the default version.
- *DavAdmin > Services > Status* now shows ports for davpanel UI, Caddy webserver and SSH service.
- Added a unified template for '[Error establishing database connection message](https://davpanel.com/docs/articles/databases/error-establishing-a-database-connection)' on DavAdmin > Users, Plans, Domains, New User, Import cPanel, DNS Zone Editor, Caddy Editor.
- *DavAdmin > Services > View Log Files* will now parse url for log_name and lines, example: http://demo.davpanel.org:2087/services/logs?log_name=Caddy%20Logs&lines=20
- Removed classes from all input fields on DavAdmin: `file:-my-2 file:-ml-2.5 file:cursor-pointer file:rounded-l-[5px] file:rounded-r-none file:border-0 file:px-3 file:py-2 file:outline-none focus:outline-none disabled:pointer-events-none file:disabled:pointer-events-none file:border-solid file:border-gray-300 file:bg-gray-50 file:text-gray-500 file:hover:bg-gray-100 file:dark:border-gray-800 file:dark:bg-gray-950 file:hover:dark:bg-gray-900/20 file:disabled:dark:border-gray-700 file:[border-inline-end-width:1px] file:[margin-inline-end:0.75rem] file:disabled:bg-gray-100 file:disabled:text-gray-500 file:disabled:dark:bg-gray-800`.
- [Relax password validations on inputs #4](https://github.com/stefanpejcic/openadmin/pull/4) for DavAdmin.
- 'ssl' module is now available in the Community edition.
- Added tooltips on *DavAdmin > Settings > General* and *DavAdmin > Plans > Edit*.
- Added log options on SiteManager for Python & NodeJS applications: [view raw log, copy to clipboard, open in new tab](/img/docs-content/QCJzGZLT-2025-11-19-15-31.png).
- User's activity log will now indicate for autologin if it occured using davpanel API or DavAdmin auto-login.
- 'activity_items_per_page' value for new installations is increased from 25 to 100.
- Pressing **Enter** in the search input field under *DavPanel > Account > Activity Log* will search all logs, while typing without pressing Enter will search only the rows on the current page.
- Start, Stop and Restart actions on any service in *DavAdmin > Services > Status* will now block further actions on all other services.
- Added timestamps in docker logs for davpanel service.
