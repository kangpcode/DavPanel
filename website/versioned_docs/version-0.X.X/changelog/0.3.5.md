# 0.3.5

Released on November 08, 2024

### 🚀 New features
- [Email notifications for DavPanel users](/docs/panel/account/notifications/).
- Option to change password for email accounts, set quota, suspend incoming/outgoing emails from the 'DavPanel > Emails' page.
- Users can now view and terminate active sessions for their account from the 'DavPanel > Account > Active Sessions' page.
- Administrators can now set [rate limiting and blocking limits](/docs/admin/intro/#brute-force-protection) for both DavPanel and DavAdmin login pages.
- Administrators can now set [session duration](https://dev.davpanel.com/cli/config.html#session-duration) for DavPanel users.
- Administrators can now create [a custom template to be displayed on domains without any content](https://i.ibb.co/tXkHKyL/default-landing.png).
- New command `davcli admin logs` is available for multitail [all DavAdmin services logs](https://dev.davpanel.com/logs.html).
- [Error IDs](https://i.postimg.cc/dtC3M7Mq/500.png) to help administrators trace DavPanel errors with the new command [`davcli error`](https://dev.davpanel.com/cli/error.html).
- [`davcli domais-delete` command](https://dev.davpanel.com/cli/domains.html#Delete-Domain).

### ️🚨 Security fixes
- *Insecure Permission Modification via Fix Permission Function* – vulnerability in 'DavPanel > Files > Fix Permissions' allowed an attacker to access other files outside of the `/home/username/` directory within the user's container.
- *Remote Code Execution via Fix Permission* – vulnerability in 'DavPanel > Files > Fix Permissions' allowed an attacker to execute commands inside the DavPanel UI container which is accessible to all users.
- *Remote Code Execution via Change Time Zone* – vulnerability in 'DavPanel > Server > Change TimeZone' allowed an attacker to execute commands inside the DavPanel UI container which is accessible to all users.
- *Unauthorized File Access via Copy Function* – vulnerability in 'copy' function on the 'DavPanel > File Manager' page allowed an attacker to access files from the DavPanel UI container.
- *Unauthorized File Access via Compress Function* – vulnerability in 'compress' function on the 'DavPanel > File Manager' page allowed an attacker to compress files from the DavPanel UI container.
- *Unauthorized File Access* – vulnerability in the url parsing on 'DavPanel > File Manager' page allowed an attacker to access files from the DavPanel UI container.
- *Unauthorized File Access via Download Function* – vulnerability in 'download' function on the 'DavPanel > File Manager' page allowed an attacker to download files from the DavPanel UI container.
- *Unauthorized File Access via View Function* – path traversal vulnerability in 'view file' function on the 'DavPanel > File Manager' page allowed an attacker to manipulate the file path and view files from the DavPanel UI container.

### 💅 Polish
- Python version for DavPanel is updated from `3.10` to `3.12`.
- [Inline documentation for every page on DavAdmin interface](https://i.postimg.cc/6tzM8Rtg/2024-10-31-20-32.png).
- `davcli user-login` will now display list of users to select and autocomplete username.
- Optimized `davpanel/davpanel:latest` docker image.
- `git` and `apparmor` are now installed automatically on Debian12.
- Email and FTP accounts for use are now deleted when DavPanel user is terminated.
- Email folders are now automatically created for new domains.
- SSL, DNS, Proxy settings, blocked IPs, ClamAV settings and websites are now automatically deleted when domain is removed.
- Terms no longer need to be accepted for new installations.
