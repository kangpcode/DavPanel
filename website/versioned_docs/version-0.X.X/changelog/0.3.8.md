# 0.3.8

Merged in version 1.0.0

### 🚀 New features
- Templates for [Suspended User](/docs/admin/services/nginx/#suspended-user-template) and [Suspended Domains](/docs/admin/services/nginx/#suspended-domain-template).
- [`davcli domains-suspend`](https://dev.davpanel.com/cli/domains.html#Suspend-Domain) and [`davcli domains-unsuspend`](https://dev.davpanel.com/cli/domains.html#Unsuspend-Domain) commands.

### 🐛 Bug fixes
- [Davpanel dashboard - FTP Accounts listed twice #292](https://github.com/stefanpejcic/OpenPanel/issues/292)
- [Davpanel - Email - manage adding filters #290](https://github.com/stefanpejcic/OpenPanel/issues/290)
- [Implement CSRF protection on all forms #272](https://github.com/stefanpejcic/OpenPanel/issues/272)
- [SyntaxError when deleting plan that has no users yet #300](https://github.com/stefanpejcic/OpenPanel/issues/300)
- Fixed bug displaying avatar type on 'DavPanel > FileManager'.
- Fixed bug with translations for 'DavPanel > SiteManager' on Flarum and WordPress templates.
- Fixed bug renewing ssl using `davcli ssl-domain` command.
- [Docker Hub unreachable with Contabo custom nameservers #294](https://github.com/stefanpejcic/OpenPanel/issues/294)


### 💅 Polish
- Storage files are no longer used for mounting user's /home directory - insted linux quotes are used.
- If ipv4 is not available on the server, new domains will instead use ipv6 in Nginx and Bind9 configuration files. [Full support for IPv6 only servers is in progress](https://github.com/stefanpejcic/OpenPanel/issues/296)
- Redesigned DavAdmin Dashboard page.
- 'DavAdmin > Users > singe user' will now display IPv6 address if set for the user.
- Suspending user will now redirect all their domains to custom [suspended_user.html](https://github.com/stefanpejcic/openpanel-configuration/blob/main/nginx/suspended_user.html) template.
- DavPanel can now be updated [directly from Github](/docs/admin/intro/#manual-updates).
- [`davcli domains-add` command](https://dev.davpanel.com/cli/domains.html#Add-Domain-to-User) will no longer allow users to add the server hostname as a domain.
- [Administrators can now prevent DavPanel users from creating certain domains](https://dev.davpanel.com/customize.html#Domain-Restriction).
- New 'Statistic' widget is added to DavAdmin Dashboard, displays total count of: users, servers in the cluster, domains, websites, emails, plans and backup jobs.
- Email address is no longer required on 'DavAdmin > Users > Add New User' page.
- Administrator can now delete suspended users from 'DavAdmin > Users' or via [`davcli user-delete` command](https://dev.davpanel.com/cli/users.html#Delete-User).
- The 'DavAdmin > Domains' section will now display the **SSL status**, whether the **domain is suspended**, and the **force HTTPS** option for each domain.
- On 'DavAdmin > Dashboard > System Information widget' update badge will be displayed when new DavPanel version is available.
- Adding license key on 'DavAdmin > License' will no longer restart DavAdmin but prompt user to restart.
- `x-csrftoken` is added to all forms on the DavAdmin interface for [CSRF](https://portswigger.net/web-security/csrf) protection.
- `--no-restart` flag is added to the [davcli license command](https://dev.davpanel.com/cli/license.html).
- 'DavAdmin > Dashboard' page will now use [Github](https://raw.githubusercontent.com/stefanpejcic/OpenPanel/refs/heads/main/version/latest) API to check the latest DavPanel version.
- unzip is removed from install scripts as it is available in the DavPanel UI container.
