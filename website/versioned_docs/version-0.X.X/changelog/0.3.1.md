
# 0.3.1

Released on October 10, 2024


### 🚀 New features
- [Temporary domains for websites added to the Site Manager interface](/docs/panel/applications/wordpress/#preview-with-temporary-link).

### 🐛 Bug fixes
- Fixed [bug #66 - Password reset for davpanel users does not end all active sessions on that user](https://github.com/stefanpejcic/OpenPanel/issues/66)
- Fixed [bug with the update script causing multiple notifications](https://community.davpanel.org/d/104-bug-in-update-script-from-029-to-030).
- Fixed [bug #197 - update command has no timeout](https://github.com/stefanpejcic/OpenPanel/issues/197).
- Fixed bug with DavAdmin service failing if /etc/cron.d/davpanel file is deleted.
- Fixed [bug #194 - DavAdmin > Settings > DavPanel error on save: Error restarting DavPanel service: '' ](https://github.com/stefanpejcic/OpenPanel/issues/194).
- Fixed [bug #195 - Partial backup job runs only for first user](https://github.com/stefanpejcic/OpenPanel/issues/195).
- Fixed bug sorting docker container stats on 'DavAdmin > Users > *user* > Usage'.
- Fixed js bug `Uncaught SyntaxError: Unexpected identifier 'bi' (at website?domain=X.com:99:609)` after user auto-logged-in to wp-admin.
- Fixed [js bug creating new plans from the DavAdmin interface on DavPanel Community edition](https://media.discordapp.net/attachments/1205652108213485571/1291779899442335927/image.png?ex=67015748&is=670005c8&hm=b74aa02b4a44c988843fd55656985702d6d279490aaf2d25186e5a90a71d097f&=&format=webp&quality=lossless&width=1162&height=614).
- Fixed js bug `Uncaught SyntaxError: Unexpected token '}' (at wordpress:19:240)` on Scan button when WordPress installations exist.
- Fixed js bug `Uncaught SyntaxError: Unexpected token 'function' (at wordpress:31:963)`when domain has punnycode.
- Fixed bug with WHMCS module not passing PackageName when creating new user account.
- Fixed bug with WHMCS module returning error messages even for successful actions.

### 💅 Polish
- The [dev_mode](https://dev.davpanel.com/cli/config.html#dev-mode) option will now also control verbose logging of API requests in `/var/log/davpanel/admin/api.log`.
- The `davcli sentinel` will now check if service is actually needed before trying to restart it.
- The `davcli report` script will now provide more detailed information aboute the DavAdmin service and installed pypthon modules.
- The `davcli config update` command will now restart services in the background, allowing for faster execution from the DavAdmin interface.
- [DavAdmin > Users > New will now display detailed log of the user account creation process](https://i.postimg.cc/XjyNsRYL/2024-10-07-16-16.png).
- [Enhanced WordPress auto-installation process](https://i.postimg.cc/9Q9cgn36/wp-installer-davpanel-032.gif).
- [Enhanced Domain addition with error reporting](https://i.postimg.cc/xTJYpTBx/adddomains-2024-10-05-17-32-24-ezgif-com-video-to-gif-converter-1.gif).
- FTP Logs are now available under the 'DavAdmin > Services > Logs' page.
- Improvements to the 'DavAdmin > Plans' page.
- 'DavPanel > FTP Accounts' page now displays server IP and ftp port for users to connect to.
- [Documented features](/docs/admin/settings/davpanel/#enable-features).
- [Restrictions and validations to MySQL and MariaDB database names, usernames and passwords](/docs/articles/accounts/forbidden-usernames/#mysql--mariadb).
- [Restrictions and validations to FTP sub-accounts and passwords](/docs/articles/accounts/forbidden-usernames/#ftp).
- [Restrictions and validations to Email accounts and passwords](/docs/articles/accounts/forbidden-usernames/#emails).
- [Improvements to the 'DavAdmin > Users > *user* > Backups' page](https://i.postimg.cc/3Nc6Kmd0/2024-09-30-14-41.png).
- [Added checks to the install script: if admin account is actually created and docker file mounted](https://github.com/stefanpejcic/OpenPanel/commit/b1ee609d0723447fccbd090d83f198949008fb42).
- For new domains, the server signature is now passed from the web server running within the user's container. For users running Apache, the headers will display Apache, and for those running Nginx, the headers will display Nginx.
- As from 0.2.9 users can enable /phpmyadmin on a per-domain base, therefor global setting is removed from /etc/davpanel/davpanel/conf/davpanel.config file and `davcli phpmyadmin` command is removed.
- `davcli webserver-check_if_file_exists` command is removed.
- `davcli php-enabled_php_versions` is now renamed to `davcli php-installed_versions`.
- `davcli php-default_php_version` is now renamed to `davcli php-available_versions`.
- `davcli php-get_available_php_versions` is now renamed to `davcli php-default_version`.
- `davcli php-install_php_version` is now renamed to `davcli php-install_version`.
- `davcli php-domain_php` is now renamed to `davcli php-domain`.
- `davcli backup-run` will now check mysql status inside user container before trying to export databases and users.
- `/backup_info/<username>` route on DavAdmin is now renamed to `/backups/restore/dates/<username>`.
- `davcli ftp-add`, `davcli user-add`, `davcli user-rename`, `davcli admin new`, `davcli admin rename` will on validation errors display links to [username/password requirements](/docs/articles/accounts/forbidden-usernames).
- New user accounts will now immediately be [displayed in 'DavAdmin > Backups > Restore' with 0 backups available](https://i.postimg.cc/WpZHbCcW/2024-10-01-12-36.png).
- `/etc/nginx/modsec/main.conf` is now renamed to `/usr/local/nginx/conf/modsecurity.conf`.
- `/davpanel`, `/davadmin` and `/webmail` will now redirect to set domains.
- The following routes are now excluded from minification and return plain text: `/view_file` (view files modal on DavPanel > FileManager), `view_ssl_file/<domain>`, (view fullchain and privkey modal on DavPanel > SSL), `domains/export-dns-zone/<domain>` (export/view dns zone on DavPanel > Domains), `check_install` (php version install log on DavPanel > PHP > Default Settings).
- websites list is removed from DavPanel > SiteManager interface.
- `davcli domains-add` command now accepts optional `--debug` flag to display verbose output.
- WordPress auto installer will now also check for index.php and wp-config.php files in install directory.
