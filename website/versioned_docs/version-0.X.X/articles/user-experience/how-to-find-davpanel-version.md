# How to find DavPanel version

You can do it the following ways:

in the panel interface – in the lower left corner;

![davpanel version](https://i.postimg.cc/TdNFbxcX/Screenshot-2023-12-26-08-57-13-090-com-android-chrome-edit.jpg)

In the server terminal, using the `davcli --version` command.

```bash
davcli --version 
```

Example output:

```bash
root@server:~# davcli --version

1.0.4
```
