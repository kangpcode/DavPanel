# Import cPanel Account

Use **DavAdmin > Backups > Import account** to create an DavPanel account from a cPanel, CyberPanel, or DavPanel backup. On the import page, select the backup file and choose the backup type (**DavPanel**, **cPanel**, or **CyberPanel**) before starting the import.

![Account Imports page with the import logs and the Import Account button](/img/davadmin-screenshots/advanced/cpanel-page.png#gh-light-mode-only)
![Account Imports page with the import logs and the Import Account button](/img/davadmin-screenshots/advanced/cpanel-page_dark.png#gh-dark-mode-only)

:::info
This menu item is only available with an **Enterprise** license and is hidden for reseller logins. A **View Logs** button on the same page links to the account import history.
:::

For detailed instructions, see the [Import cPanel backup guide](https://davpanel.com/docs/articles/transfers/import-cpanel-backup-to-davpanel/)
