# License

Add your DavPanel Enterprise license key to unlock premium features.

## License Key

Enter your [DavPanel Enterprise edition](https://my.davpanel.com/clientarea.php?action=products) license key here. Activating the license enables advanced capabilities such as:

* Email and FTP account management
* Reseller management
* API access
* Billing integrations with WHMCS, FOSSBilling, and more

![License key section with the key field, the Save key, Re-Verify and Downgrade buttons and the license details](/img/davadmin-screenshots/license-key.png#gh-light-mode-only)
![License key section with the key field, the Save key, Re-Verify and Downgrade buttons and the license details](/img/davadmin-screenshots/license-key_dark.png#gh-dark-mode-only)

For a step-by-step activation process, see the [Upgrading to DavPanel Enterprise and activating License guide](/docs/articles/license/upgrade_to_davpanel_enterprise_and-activate_license/).
