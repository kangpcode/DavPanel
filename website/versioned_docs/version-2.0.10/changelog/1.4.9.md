Released on July 14, 2025

### 💅 Polish
- `davcli domains-user` and `davcli domains-all` scripts now accept optional flags to display document root or php version.
- `davcli domains-add` now accepts optional flags to skip creating virtualhost files, reverse proxy, dns zones, or starting services.
- optimized `/json/ips` page on DavAdmin.
- changing ip address for user now immediately invalidates all cache.
- *DavAdmin > Users* table now indicates dedicated ip address for user.
- [IP is no longer enforced for DavPanel UI access when IP address is used](https://github.com/stefanpejcic/OpenPanel/discussions/553#discussioncomment-13733616)
- `davcli websites-google_indexed` is removed.
- [*DavAdmin > Users > single user* page no longer displays 500 error when docker stats for user are missing](/img/docs-content/PT9gyNN9-2025-07-14-14-42.png).
- `/get_user_stats` route on DavAdmin is removed.
- [[Enhancement] Make this date human readable #555](https://github.com/stefanpejcic/OpenPanel/issues/555)


### 🐛 Bug Fixes
- fixed several bugs on `/websites` page when IDN domain name is used.
- fixed issue preventing dedicated ip address to be displayed for users on *DavAdmin > Users* table.
- fixed bug setting user's dedicated ip address in DNS zone for new domains.
- [Bug in DavPanel UI on /website - delete Node/Py app not working #558](https://github.com/stefanpejcic/OpenPanel/issues/558)
- fixed *Warning: invalid webserver type selected: openresty. Must be 'nginx', 'apache', 'openresty', 'varnish+nginx', 'varnish+apache' or 'varnish+openresty'. Using the default instead..* when openresty is set.
- [Can't Enable/Disable container on user Services on DavAdmin #566](https://github.com/stefanpejcic/OpenPanel/issues/566)
- [Showing old metric after resource update #565](https://github.com/stefanpejcic/OpenPanel/issues/565)
- fixed js bug `Uncaught SyntaxError: redeclaration of const files` preventing file uploads in File Manager.
- fixed css bug with actions dropdown not visible on *DavPanel > Domains* by default.
