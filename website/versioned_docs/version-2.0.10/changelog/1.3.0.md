Released on May 18, 2025

### 💅 Polish
- [dev_mode](https://dev.davpanel.com/cli/config.html#dev-mode) now replaces locally build css/js files with cdn.
- Softaculous 'autoinstaller' module is removed as it is not production ready.
- `davcli admin off` will now create a lock file `/root/davadmin_is_disabled` that is checked on DavAdmin startup.
- `/api/backups/settings` route is removed.
- title in FileManager pages will now display the path in order to allow setting folder as Favorite.
- added language switcher on DavPanel login page.
- [Ukrainian and Russian translations](https://community.davpanel.org/d/165-govoris-po-russki-russian-and-ukrainian-translation-for-davpanel).

### 🐛 Bug Fixes
- fixed 'Aw Snap!' error on Chrome when accessing DavAdmin.
- fixed css bug on DavAdmin pages: process manager, ftp, locales.
- fixed css bug on davadmin new user creation output.
- fixed error `error mounting "/etc/timezone" to rootfs` when starting DavPanel container on RockyLinux 9.3
- fixed css bug with favicon star icon on dark mode on *DavPanel > Dashboard*.
- fixed 500 error on *DavPanel > Databases* page.
- fixed css issue with all fields in drawers on *DavPanel > FileManager*.
- fixed bug setting cpu/ram limits for services on *DavPanel > Docker > Containers* when total limits are unlimited.
- fixed js error `Uncaught TypeError: Assignment to constant variable.` when editing wp-config.php file in FileManager.
- fixed [bug encoding DavAdmin updates for ARM cpu](https://community.davpanel.org/d/162-error-on-oracle-free-tier-arm/4).
- fixed [Bug visible dropdown menu Administrators page](https://community.davpanel.org/d/163-bug-visible-dropdown-menu-administrators-page).
