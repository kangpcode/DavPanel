Released on March 27, 2025

### 💅 Polish
- config cache is now invalidated after changing update preferences on *DavAdmin > Settings > Updates* page.
- changed font on *DavPanel > Dashboard* icons.
- added `mod_rewrite` by default in httpd.conf template for Apache.
- added tooltips on *DavAdmin > Users* table for CPU, Memory, Disk and Inodes usage.
- added timestamp when docker stats was last updated for user on *DavAdmin > Users > single user* page.
- added Overview section on *DavAdmin > Users > single user* page.
- added 'User Activity' and 'System Information' widgets to *DavAdmin > Dashboard*.
- limited number of lines for flash messages after password change on *DavAdmin > Resellers* page.
- *PM2* module is now disabled by default for new installations.
- added *backup* services for users, allowing them to backup volume data to: WebDAV, SSH/SFTP, Azure Blob, Dropbox or S3 compatible storage.

### 🐛 Bug Fixes
- fixed bug on *DavPanel > FileManager* with option: *Open in File Editor after creation*.
- fixed css issue selecting *Up one folder* row on *DavPanel > FileManager* table.
- fixed error *NameError: name 'webserver' is not defined* on */system/hosting/plan* page.
- fixed bug detecting php version from apache conf on WordPress autoinstall: *Starting PHP container: php-fpm-/:*.
- fixed bug *Starting PHP container: php-fpm-8.2* on WordPress autoinstall on Nginx due to WPCLI command not yet installed in container.
- fixed error on WordPress uninstall when wp-config.php is missing.
- fixed bug displaying folders on *Disk Usage* and *Inodes Explorer* pages.
- fixed bug with search on *DavAdmin > Notifications* page.
- fixed error on *DavAdmin > Users* with stats for suspended users.
- fixed bug restarting admin service on installation when license key is added.
- fixed error restarting DavAdmin service from *DavAdmin > License* page.
- fixed bug with *DavAdmin > Plans > Edit* appending extra *g* at the end of Memory limit value.
- fixed bug with the search on *DavAdmin > Domains* page.
- [Error 500 after login #383](https://github.com/stefanpejcic/OpenPanel/issues/383)
