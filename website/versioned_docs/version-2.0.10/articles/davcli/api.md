# API

:::info
API access is available only on [DavPanel Enterprise edition](https://davpanel.com/beta/)
:::

## Enable

To enable DavAdmin API access:

```bash
davcli api on
```

## Disable

To disable DavAdmin API access:

```bash
davcli api off
```

## Status

To check current DavAdmin API status:

```bash
davcli api status
```

## API list

`davcli api list` displays all available api endpoints for the installed DavAdmin version.

```bash
davcli api list
```
