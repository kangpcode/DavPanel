# Manually Update

When a new update is available, you will receive a notification in the DavAdmin panel.

<Tabs>
  <TabItem value="davadmin-admin-update-now" label="With DavAdmin" default>

To manually update DavPanel, navigate to **DavAdmin > Settings > Update Preferences** and click on the "Update Now" button.

NOTE: update is visible only if newer version is available.

  </TabItem>
  <TabItem value="CLI-update-now" label="With DavCLI">

To update DavPanel manually from the terminal, run the following command:

```bash
davcli update --force
```
[Documentation for `davcli update` command](https://dev.davpanel.com/cli/update.html)

  </TabItem>
  
</Tabs>
