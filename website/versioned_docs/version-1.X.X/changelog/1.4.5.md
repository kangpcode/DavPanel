Released on June 28, 2025

### 💅 Polish
- [added disk IO information on DavAdmin > Dashboard](/img/docs-content/LHnNj8kV-2025-06-25-18-11.png).
- [added network IO information on DavAdmin > Dashboard](/img/docs-content/74cY3t41-2025-06-25-18-12.png).
- option to rollback davpanel ui from *DavAdmin > Settings > Updates* page.
- option to delete feature set, enable all features or disable all features on *DavAdmin > Hosting Plans > Feature Manager*.
- Page links and description tooltips for features table on *DavAdmin > Hosting Plans > Feature Manager*.
- busybox container is no longer used in user panel operations.
- example services are removed from docker-compose.yml file: busybox, filebrowser, uptimekuma, mssql, minecraft.
- `SSH_PORT` and `TTYD_PORT` variables are renamed to `UNUSED_1_PORT` `UNUSED_2_PORT` and can be used for adding custom services for user.
- [documented guidelines for adding new services in DavPanel](https://dev.davpanel.com/images/)
- rewritten Informations, Usage and Statistics widgets on *DavPanel > Dashboard*.
- Statistics widget now displays when was data last updated.
- [Option to Enable/Disable containers on Services tab in DavAdmin [FEATURE REQUEST] #523](https://github.com/stefanpejcic/OpenPanel/issues/523)
- added storage information on single user page DavAdmin: Volumes, Containers and Images.
- `mail_debug` setting is added, allows storing all outgoing emails from the system (DavAdmin and DavPanel UI) to `/var/log/davpanel/admin/emails/` directory.
- added `restart: unless-stopped` policy for varnish service.
- DavAdmin > Advanced > Migrate

- fixed bud dispalying `0` instead of `∞` on *DavAdmin > Users* table for unlimited usage.
- fixed bug preventing empty email on *DavAdmin > Settings > Notifications*.
