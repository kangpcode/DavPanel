### 🎨 Polish
- Default cpu/ram limits for new python/nodejs apps is now 1.0.
- Search results in DavPanel UI for Enterprise edition now include: domains, websites, emails, ftp accounts, databases, crons, files, folder, containers, services.
- When `dev_mode` is enabled, all `docker logs davpanel` entries now include the module name, making it easier to identify which component generated each log or error. For example: `MYSQL - Checking database sizes...`.
- DavAdmin Admin login notifications now check logins agains the ssh whitelist.
- Improvements to the DavPanel UI sidebar.
- Private notes for users are now editable from DavAdmin > Users table.
- Added loading/double-submit protection to on all form submissions in DavPanel UI pages.
- [DavAdmin service restart breaks UI #1014](https://github.com/stefanpejcic/OpenPanel/issues/1014)
- Added unified 'Password Strength' setting for all password fields in DavPanel UI pages.
- Added validation messages to all input fields in DavPanel UI pages.
- DavPanel restart is no longer needed when changing permisisons for a single user or editing feature sets.
- Editing plan limits, changing plan for user, and changing IP for user no longer drop all redis cache.
- Removed 'rounded-lg' class from all input fields and selects in DavPanel and DavAdmin templates.
- `davcli domains-suspend` command now accepts optional `--comment='reason'` flag.
- User can now specify a reason why domain is suspended when suspending domain from DavPanel. Reason is visible later on DavPanel > Domains table.
- Added confirmation prompts for all text-area forms on DavPanel and DavAdmin templates.
- Removed 'select-none' class from all tables on DavPanel and DavAdmin templates.
- Added an option to delete images from *DavPanel > Containers > Image Updates*.
- [Default cpu/ram limits are increased form 0.5 to 1.0 for php versions on new installs](https://github.com/stefanpejcic/openpanel-configuration/commit/feaf57d90660e6d83cda5d1e12ec697be6fd8919).
- [opcache is now enabled by default on new installs and execution limits increased](https://github.com/stefanpejcic/openpanel-configuration/commit/a9e7097576160dd7f92e4e31010d71103616d6cb).
- Optimized default configuration files for services: PHP, Nginx, OpenLitespeed, Apache, MariaDB, PostgreSQL on new installs.
- Added option to restore defualt webserver conf from *DavPanel > Configuraton Editor* page.
- added an option to restore DavPanel acocunts from full account backup in *DavAdmin > Advanced > Import backup*.
