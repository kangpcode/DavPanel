Released on August 15, 2025

### 💅 Polish
- [BETA support for OpenLitespeed](https://community.davpanel.org/d/180-beta-testers-wanted-openlitespeed-davpanel)
- [Added RNAME to default DNS zone templates](/docs/admin/domains/dns_templates/#available-template-variables) - suggested by Dominik.
- added descriptive error messages for failed auto-login on WP Manager.
- added [*DavAdmin > Services > Limits*](/docs/admin/services/limits) page where Administrators can set limits for webserver, dns, davpanel UI and other system services.
- `fonts.googleapis.com`, `gstatic.com`, `api.github.com`, `app.grapesjs.com`, `fonts.bunny.net` and `fonts.gstatic.com` removed from CSP header.
- added html IDs to all sections in *DavPanel > Dashboard* to be used for custom css.
- `Failed to load speed data` is removed from /sites when data is missing.
- [password reset functionality is restored](https://davpanel.com/docs/panel/intro/#password-reset).
- *restart needed* button on DavAdmin > Dashboard is now visible to Reseller users as well.
- [Added resource usage widget on top-right of DavAdmin](/docs/admin/dashboard/#sse-usage).
