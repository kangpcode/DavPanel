# Blesta

DavPanel Enterprise edition has billing integrations with [WHMCS](/docs/articles/extensions/davpanel-and-whmcs/), [FOSSBilling](/docs/articles/extensions/davpanel-and-fossbilling/) and Blesta.

### Blesta extension by BlestaClub
DavPanel Blesta extension allows users to integrate billing automations with their DavPanel server.  

**Provided by BlestaClub:**  
https://blesta.club/extensions/davpanel

---

### Open-source Blesta module
An open-source Blesta module for DavPanel is also available, maintained by the community.  

**GitHub repository:**  
https://github.com/Equitia/blesta-module-davpanel
