# davpanel-tests

Generate new tests with:
```bash
cd ~/playwright-test && npx playwright codegen https://DAVPANEL_URI
```

Re-download tests from git:
```bash
cd ~/playwright-test && git pull
```


---

Server install:

```bash
bash <(curl -sSL https://raw.githubusercontent.com/kangpcode/davpanel-tests/refs/heads/main/INSTALL.sh)
```
